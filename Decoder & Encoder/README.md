# Decoder & Encoder

This task focuses on implementing and testing **parameterized Decoder and Encoder modules** in Verilog.

- **Decoder:** Converts a binary input into a one-hot output when enabled.
- **Encoder:** Converts the one-hot input back into its binary index.
- The testbench verifies that the Encoder and Decoder work correctly together.

The main goal is to practise **parameterization, combinational logic, and basic RTL verification**.
