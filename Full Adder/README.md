# Full Adder

This task focuses on implementing and testing a **Full Adder** in Verilog.

The design is implemented using different coding styles:

- **Gate-Level:** Built using logic gates.
- **Structural:** Built by connecting Half Adder and Full Adder modules.
- **Behavioral:** Described using arithmetic operations.

The testbench compares the different implementations to verify that they produce the same results.

The main goal is to practise **Verilog coding styles, module instantiation, and RTL verification**.
